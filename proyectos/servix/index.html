ServiX

Gestión de servicios técnicos del hogar con asistente de IA que escala a un administrador.

Terminado · pruebas unitarias y CI

Ver repositorio

Capturas

Pantallas renderizadas desde el código de la app. Con datos de demostración.

Contexto

Proyecto de Optativa III (Aplicaciones Móviles), Universidad de San Buenaventura. Equipo de tres con roles Scrum; mi rol fue Developer.

Problema

Un negocio de servicios técnicos del hogar necesita registrar clientes y órdenes, dar seguimiento al estado de cada servicio y atender consultas sin depender de llamadas.

Solución

App con roles de administrador y cliente, órdenes y historial por usuario, notificaciones y un chat con Gemini que responde dudas frecuentes y puede derivar la conversación a un administrador.

Arquitectura

  • UI (Compose) → ViewModel → UseCase → Repository → Data Source
  • Firebase Authentication y Cloud Firestore; cada usuario accede solo a su árbol usuarios/{uid}/…
  • Gemini mediante Firebase AI Logic: no hay claves de IA en el APK
  • Webhook de Make para eventos de servicio (URL por local.properties)
  • Azure Pipelines: compila, ejecuta pruebas unitarias y publica el APK debug

Funcionalidades

  • Clientes, órdenes de servicio e historial
  • Rol administrador y portal de cliente
  • Chat con IA y bandeja de escalamientos
  • Notificaciones y reglas de Firestore por rol

Aprendizajes técnicos

  • Los repositorios simulados permiten renderizar y probar las pantallas sin depender de Firebase.
  • Mover la IA a Firebase AI Logic evita publicar claves en el APK.
  • Las reglas por usuario y rol deben diseñarse junto con el modelo de datos, no después.

Tecnologías

  • Kotlin
  • Jetpack Compose
  • Material 3
  • Firebase Auth
  • Firestore
  • Firebase AI Logic
  • Make
  • Azure DevOps

Pruebas y resultados

  • Compilación y pruebas unitarias ejecutadas en CI (Azure Pipelines)
  • Scrum, backlog y pipeline documentados

Alcance y decisiones

  • El webhook de Make es configurable: sin URL no se envían eventos
  • La IA se consume desde Firebase AI Logic, sin claves en el APK
